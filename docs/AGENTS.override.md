# docs/AGENTS.override.md

This directory is the project documentation area and should be used only for documentation-related content.

## Scope

- This folder is reserved for documentation, reference material, planning notes, and project guidance.
- Content here should support understanding, maintenance, onboarding, and communication about the project.
- Documentation in this folder should remain clear, factual, and useful to humans reviewing the project.

## Use this folder for

- Project overview and architecture notes
- Setup and usage instructions
- Feature documentation
- Operational guidance and runbooks
- Design notes and process documentation
- Future planning documents, roadmaps, and strategy summaries
- SEO and discoverability planning for public-facing content

## Do not use this folder for

- Source code implementation
- Application logic or runtime behavior
- Database schema or migration logic
- Build scripts, config generation, or executable automation
- Temporary notes that are not intended to be kept as documentation

## Documentation standards

- Prefer concise, structured markdown
- Use headings, lists, and examples where helpful
- Keep instructions specific and actionable
- Separate ideas, status, and decisions clearly
- Avoid mixing product implementation details with general documentation

## Summary
