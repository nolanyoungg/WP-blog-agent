# Blog Generation Manual

This folder is for the blog content that the model will generate. The Excel files and structured data used in this workflow are not to be altered in structure.

Important rules:
- Do not modify the structure of any Excel file used for these blogs.
- Do not add, remove, rename, reorder, or reformat columns, tabs, headers, or fields.
- Do not change formulas, data layout, or spreadsheet conventions unless explicitly approved.
- Before modifying this file or any related spreadsheet, ask for permission first and wait for explicit approval.

This is intended to preserve the integrity of the blog-generation workflow and keep the data model stable for generated content.
